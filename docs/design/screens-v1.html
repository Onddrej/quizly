Quizly

Návrh obrazoviek, prvá verzia

Sedem obrazoviek pokrýva celý postup učenia: výber setu, vytvorenie setu z vloženého zoznamu, kartičky a Learn mód po kolách. Kartičky, odpovede aj tlačidlá výslovnosti fungujú, môžeš si ich vyskúšať.

Dizajnové rozhodnutia

  • Rozloženie a postupy ako v Quizlete. Stránka setu s módmi učenia, otáčacie kartičky so zaraďovaním, Learn po kolách. Vlastný názov, bez loga Quizletu.
  • Svetlá a tmavá téma podľa nastavenia telefónu. Tmavá používa tmavomodrú, večer šetrí oči. Vyskúšaj prepínač hore.
  • Reproduktor pri každom anglickom slovíčku. Používa hlasy telefónu; americký alebo britský prízvuk si zvolíš v nastaveniach.
  • Learn mód. Kolo má 7 slovíčok. Nové prídu ako výber z možností, po jednej správnej odpovedi ich píšeš, chyba slovíčko vráti späť. Set je hotový, keď sú všetky slovíčka zvládnuté.
  • Jedna modrá pre akcie, tri farby pre pokrok. Akcie Viem / správne Ešte sa učím Nesprávne
  • Všetky slovíčka, sety a čísla sú len ukážkové. Appka začne prázdna, kým nepridáš vlastné sety.
